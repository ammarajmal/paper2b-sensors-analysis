Stage: S2c (detection-admissibility threshold: candidate rules, owner decision O4)   Date written: 2026-10-16 (BEFORE any threshold analysis)
Problem (owner: "the circular issue is valid"): the candidate gate (Wilson >= 0.95, margin >= 30, speed <= 27.75 px/frame) was derived from the same 21 conditions it classifies. We therefore keep several candidate rules, evaluate them on data NOT used to set them, and select after the results (selection recorded in DECISIONS.md).
Data: development = the 21 main-campaign conditions (S2 detections, passed gate). Validation = the 21 five-second repeat recordings (wtt_5sec; detections to be produced with the same S2 code, no frozen reference exists, so only internal consistency is checked there). Per-frame speed = image-plane centroid speed in px/frame, from the nearest detected neighbours on each side (so it is defined across a miss burst).
Outcome (defined independently of every rule): a frame is a miss if no tag with id 0 is detected.
Candidate rules (4 fixed now):
 R1 physics (no free parameter): speed per frame <= one cell width = tag side / 10 (tag36h11 is 10 cells wide including the border; side measured per stream from the corners; about 29 px at 290 px).
 R2 data midpoint (the existing rule): midpoint between the largest speed among streams with no misses and the smallest speed across a miss burst; evaluated by leave-one-condition-out (derive on 20 conditions, test on the 21st) and on the 5-second bags.
 R3 logistic: P(miss | speed) by logistic regression on development frames; thresholds at P = 0.05 and 0.5, with a 95% interval from a bootstrap that resamples whole conditions (cluster bootstrap, 2,000 resamples); the lower interval bound is the conservative threshold; validated on the 5-second bags.
 R4 speed-free robust outlier rule: per stream, flag frames whose decision margin is below median - 3 x 1.4826 x MAD (Hampel); compare the flagged frames and streams with R1-R3 and with the observed misses.
Other tests to report (not rules): Spearman correlation of speed with decision margin; whether e20 cam3 (100% detected at the highest speed) is an outlier in the speed-margin relation (Grubbs / robust z); Wilson 95% lower bound of completeness per stream under each rule.
Evaluation (fixed now): frame level: sensitivity and specificity for predicting misses, and AUC for the continuous predictors (speed, margin); stream level: agreement with the ledger classification (60 admissible, e20 cam1 and cam2 rejected, e20 cam3 diagnostic-only), reported with the 2-by-2 counts; threshold stability: width of the cluster-bootstrap interval; out-of-sample: all of the above on the 5-second bags, and for R2 on the held-out condition.
Failure means: no rule is stable out of sample; then the manuscript states the gate as an empirical observation of this dataset and does not generalise it.
