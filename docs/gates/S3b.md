Stage: S3b (timebase shifts on refined frequencies)   Date written: 2026-10-18 (BEFORE the run)
Reason: the S3 timebase shifts are differences between peaks on a grid of step RI/10, so they are quantised (0.0, 0.1, ...) and tab:timebase of the Sensors manuscript (printed max 0.106 / 0.064 / 1.492, median 0.016 / 0.004 / 0.030, streams > 0.1: 1 / 0 / 11) cannot be compared cell by cell (S8b finding). The 59.94 Hz treatment was not rebuilt.
Method: same signal and stream set as S3 (60 admitted streams; e20_320rpm cam3 diagnostic reported separately). For each treatment the rank-1 grid peak is refined by the S3 sinusoid fit (spectral.fit_sinusoid_freq, frequency free within +/- RI of the grid peak). Shift = |f_refined(treatment) - f_refined(record stamps)| / RI of the stream. Treatments: header stamps (E2); linear interpolation of the record-stamp series onto uniform 60 Hz (E3); the same onto uniform 59.94 Hz (E3b, new); nominal 60 Hz frame index with stamps ignored (E4).
Pass criteria: (1) the refined record-stamp frequency reproduces the S3 column f_refined for every stream (max abs difference <= 1e-9 Hz); (2) every treatment is evaluated for all 61 streams with no missing value; (3) two runs give identical output; (4) the S3 and S8 ledger rows already built are not changed (the new rows use the new group TBASE2; existing TBASE rows are kept and labelled as grid-quantised).
Not a criterion: agreement with the printed table. Differences are findings.
Result (2026-10-18; scripts/run_s3b.py; results/s3b_timebase_refined.csv; ledger group TBASE2): all four criteria met. (1) refined record-stamp frequency equals the S3 f_refined (max difference 1.8e-15 Hz); (2) 61 streams x 4 treatments, 0 missing; (3) two runs byte-identical; (4) existing ledger rows unchanged (0 changed, 0 missing; 5,007 rows, independent recompute 0 differences).
Refined shifts in Rayleigh intervals, 60 admitted streams (max / median / streams > 0.1): header stamps 0.034 / 0.000 / 0; uniform 60 Hz 0.051 / 0.0004 / 0; uniform 59.94 Hz 0.034 / 0.0002 / 0; nominal 60 Hz index 1.484 / 0.043 / 5. Diagnostic e20 cam3: all <= 0.001.
Against the printed tab:timebase (60 Hz 0.106 / 0.016 / 1; 59.94 Hz 0.064 / 0.004 / 0; nominal 1.492 / 0.030 / 11): the nominal-index maximum agrees to 0.5% (1.484 vs 1.492), but the interpolation shifts are about half the printed ones, the nominal median is 0.043 vs 0.030, and 5 rather than 11 streams exceed 0.1. The printed method is not documented, so the cause is not identified; the printed values do not reproduce under either the grid-peak (S3) or the refined-frequency (S3b) definition. Conclusion for the paper: under the refined definition the timestamp treatments for interpolation move peaks by at most 0.05 Rayleigh intervals, so the qualitative statement (native timestamps are a tested choice, not a large contribution; ignoring timestamps matters up to 1.5 intervals) holds, but the table numbers should be replaced by these.
