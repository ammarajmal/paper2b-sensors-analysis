Stage: S8 (number ledger and manuscript number check)   Date written: 2026-10-17 (BEFORE the ledger is built)
Purpose: every number the manuscripts take from the rebuild comes from one table (results/ledger.csv) with its provenance, and every number printed in a manuscript can be checked against it.
Ledger rows (scripts/build_ledger.py): id, group, description, value, unit, population/session, source_file, source_key (column and selector), producing script, git commit of the repository at build time, sha256 of the source file. Content: reference frequencies, timing census, detection counts, spectra peaks, laser session statistics, S6 headline metrics (rules a, b, d; arms A, B; primary quantities), S6b labelled exploratory, S7 medians and coverage, open-issue checks. Rows from exploratory variants carry group prefix EXPL_. No number enters the ledger by hand; each is read from a results file by a stated key.
Checker (scripts/check_number_ledger.py), two parts:
 (1) Curated claims: a hand-written file results/claims_map.csv links named manuscript claims (register rows R001-R005, frequencies, timing facts, counts) to a ledger id and the printed value; the checker reports AGREE (equal at the printed precision), DIFFER (with both values) or NOT_IN_LEDGER.
 (2) Full scan: every numeric token in the two manuscripts (Sensors main .tex, Measurement sections .tex) is listed with file, line and context and flagged VALUE_IN_LEDGER (equal at the printed precision to some ledger value; this is a value coincidence, NOT proof that it is the same quantity) or NO_LEDGER_VALUE. Counts are reported per file.
Pass criteria (about the machinery, not about the manuscripts):
 P1 every ledger row has all fields filled; the source value is re-read independently by the checker and equals the ledger value (tolerance 0);
 P2 building the ledger twice gives byte-identical files;
 P3 the checker runs to completion on both manuscripts and writes results/number_check_report.csv and results/number_check_summary.md;
 P4 no ledger value is computed from a manuscript;
 P5 curated claims cover at least R001-R005 and the reference frequencies, each with a status.
Not a criterion: that manuscript numbers agree with the ledger. DIFFER and NO_LEDGER_VALUE are findings for the owner; the manuscripts are not edited in this stage.
