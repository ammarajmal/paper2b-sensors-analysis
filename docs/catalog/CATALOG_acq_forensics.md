## Folder summaries

- **00_START_HERE**: This folder contains documentation and progress reports related to the investigation of 9 Hz timing issues in the acq_forensics project, focusing on spectral analysis and data acquisition methods. (role: spectral; key: MASTER_PROGRESS_REPORT.md, README.md, PATHS.md, CATALOG.csv, acq_forensics)
- **reports/current**: This folder focuses on investigating timing issues, resampling procedures, and spectral analysis related to 9 Hz phenomena in camera systems. It includes reports on acquisition architecture, timing integrity, and methods for analyzing motion and frame-rate data. (role: spectral; key: NINE_HZ_DIAGNOSTIC_EXECUTION_PLAN.md, SOURCE_SUPPORTED_ACQUISITION_ARCHITECTURE.md, THREE_DATASET_TIMING_INTEGRITY_REPORT.md, TIMING_FIX_COMPARISON_AND_FINAL_METHOD.md, STATIONARY_FEATURE_CHECK_RESULTS.md)
- **reports/superseded**: This folder contains superseded research files related to acquisition architecture, DSP preprocessing, execution approval, data visualization, resampling methods, 9 Hz hypothesis testing, novelty validation, next experiments, tracking methods, code audits, and dataset timing analysis, all within the context of acq_forensics and timing investigations. (role: mixed; key: NINE_HZ_HYPOTHESIS_AND_TEST_REGISTER.md, HISTORICAL_RESAMPLING_LINEAGE.md, RECOMMENDED_NEXT_EXPERIMENT.md, SIX_METHOD_IMPLEMENTATION_PLAN.md, GRAFANA_RESEARCH_PORTAL_ARCHITECTURE.md)
- **scripts**: This folder contains scripts for analyzing and extracting timing data from G2 outputs, comparing timing methods, and investigating 9 Hz frequency patterns in ROS bag files. It focuses on synchronization, spectral analysis, and metadata extraction for timing integrity. (role: spectral; key: g2_analyze.py, g2_timing_spectra.py, nine_hz_frozen_tables.py, probe_bag.py, timing_methods_compare.py)
- **scripts/desktop_package**: This folder contains scripts for investigating timing and acquisition methods in G3 and G4 runs, focusing on flicker detection, luminance spectra computation, and comparison of signal processing techniques. It includes tools for processing data, analyzing stationary features, and generating CSV outputs for further analysis. (role: mixed; key: g3_static_luminance.py, g4_g3_wtt.py, run_all.sh, stationary_check.py, README.md)
- **scripts/inline_reconstructed**: This folder contains Python scripts for analyzing spectral data, testing harmonic relationships in frequency lines, and classifying fps consistency issues in camera data. The scripts focus on signal processing, timing analysis, and data validation. (role: spectral; key: e8_band_peak_all_streams.py, e9_harmonic_test.py, fps_consistency_classify.py, README.md)
