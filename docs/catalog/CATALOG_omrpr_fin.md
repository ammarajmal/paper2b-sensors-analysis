## Folder summaries

- **docs**: This folder contains documentation and analysis related to the OMRPR project, focusing on pipeline steps, validation results, and critical analysis of measurement systems. It includes files on data processing, synchronization, uncertainty quantification, and figure generation for manuscript preparation. (role: figures; key: OMPRP_SUPERVISOR_GUIDELINE.md, RESULTS_LOG.md, claude_session_2026-07-03_pipeline_and_figures.md, pipeline_diagram.md, claim_boundary.md)
- **docs/_archive**: This folder contains archived documentation related to the OMRPR project, including critical analyses, methodological reviews, and audit records. It serves as a historical reference for past decisions, canonical values, and validation results. (role: manuscript; key: CRITICAL_ANALYSIS_REVISED_20260622.md, current_ground_truth_audit_2026-06-23.md, DEEP_METHODS_REVIEW.md, walkthrough_log.md, README.md)
- **src**: This folder contains a comprehensive pipeline for processing and analyzing data from the OMRPR experiment, including data acquisition, detection, calibration, pose estimation, spectral analysis, and comparison with LDV measurements to generate publication-ready figures and results. (role: comparison; key: comparison_plots.py, comparison_plots_v2.py, step12_figures_tables.py, step10_ldv_comparison.py, step07_motion_decompose.py)
