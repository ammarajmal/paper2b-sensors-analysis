## Folder summaries

- **experimental_analysis/scripts**: This folder contains scripts for analyzing multi-camera displacement experiments, processing ROS bags for AprilTag detection, and calculating pixel coverage for visualization and performance evaluation. (role: detection; key: analyze_experiments.py, process_all.sh, tag_pixel_coverage.py)
- **experimental_analysis/scripts/dynamic_test**: This folder contains scripts for analyzing and debugging wind tunnel experiments, including data acquisition, synchronization checks, 3D trajectory reconstruction, and computation of structural metrics like bending and torsion. (role: mixed; key: analyze_wtt.py, debug_3_wtt.py, debug_cam12_wtt.py, debug_wtt.py, Recorder_WTT.py)
- **experimental_analysis/scripts/dynamic_test/PlanA**: This folder contains scripts for performing sanity checks on multi-camera bag files, aggregating results, and generating diagnostic plots for trend analysis across experiments. (role: utility; key: A1_run_all_sanity_checks.py, A2_aggregate_sanity_reports.py, A_sanity_check_bagfiles.py)
- **experimental_analysis/scripts/dynamic_test/rest**: This folder contains scripts for wind tunnel experiments involving multi-camera data acquisition, AprilTag detection validation, synchronization analysis, and advanced analytics for displacement and spectral tracking. (role: mixed; key: STEP1_WTT.py, PlanB_detect_apriltag_validate.py, step2b_analysis_aggregation.py, step3a_extract_and_fuse.py, unified_check.py)
- **experimental_analysis/scripts/static_tests/bagfiles**: This folder contains scripts for processing and analyzing static test data from ROS bagfiles, including capturing data, checking integrity, detecting AprilTags, merging jitter and FPS results, and generating plots for analysis. (role: mixed; key: run_all_steps.py, step1_capture_bags.py, step3_detect_apriltags.py, step4_merge_jitter_fps.py, gen_.sh)
- **experimental_analysis/scripts/static_tests/bagfiles/cam2_working scripts**: This folder contains scripts for recording and analyzing static camera data in a wind-tunnel environment. It includes steps for capturing data, checking integrity, detecting AprilTags, merging results, and generating plots for analysis. (role: mixed; key: run_all_steps.py, gen_.sh, step3_detect_apriltags.py, step5_plots.py, step2_check_integrity.py)
- **experimental_analysis/scripts/static_tests/bagfiles/old**: This folder contains scripts for analyzing ROS bag files generated from static camera data in a wind-tunnel experiment. The scripts focus on detecting AprilTags, analyzing jitter, computing frame rates, and generating statistical summaries for timing and spectral analysis. (role: mixed; key: detect_apriltags_from_bags_step3.py, static_bags_fps_and_jitter_analysis_step5.py, check_captured_bags_step2.py, analyze_bag_detections_step4.py, detect_one_bagfile.py)
- **experimental_analysis/scripts/static_tests/images**: This folder contains scripts for capturing images, detecting AprilTags in static images, and aggregating detection results for analysis. It supports static test execution and data collection for displacement metrics. (role: detection; key: analyze_image_detections.py, detect_apriltags_from_images.py, capture_images.py)
