## Folder summaries

- **docs**: This folder contains documentation and scripts related to the OMRPR project, including audit plans, supervisor guidelines, setup guides, and manuscript status tracking. It focuses on reproducibility, implementation decisions, and project governance. (role: manuscript; key: OMRPR_SUPERVISOR_GUIDELINE.md, state_omrpr_manuscript_fin_run.txt, OMRPR_MASTER_AUDIT_SENSORS.md, omrpr_ubuntu24_bootstrap.sh, gemini_Revised OMRPR Project Publication Readiness Analysis.md)
- **legacy_src**: This folder contains a comprehensive set of scripts for processing and analyzing data from a wind tunnel experiment, including data acquisition, camera calibration, pose estimation, spectral analysis, and comparison with LDV measurements. It also includes tools for generating publication-ready figures and handling uncertainty in the results. (role: mixed; key: step00_bag_audit.py, step07_motion_decompose.py, step10_ldv_comparison.py, step12_figures_tables.py, step05_synchronize.py)
- **results/e20_detection_audit**: This folder contains research files focused on analyzing and improving the detection performance of the e20 camera system, including failure mode analysis, recovery experiments, and comparisons with baseline data. (role: detection; key: audit_analyze.py, audit_detect.py, e20_failure_mode_summary.md, e20_recovery_report.md, recovery_experiment.py)
